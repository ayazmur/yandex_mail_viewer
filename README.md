# yandex_mail_viewer

Мини-веб-клиент Яндекс.Почты на Django: список писем по папкам, чтение и отправка.
Работает через IMAP/SMTP по паролю приложения, разворачивается в GitHub Codespaces
по той же схеме, что и соседний проект `yadisk_viewer_project`.

## Что умеет

- вход: адрес `@yandex.ru` + **пароль приложения** для «Почты»;
- список папок; письма **склеиваются в треды по теме** (`Re:`/`Fwd:`/`Ответ:` и т.п.),
  тред раскрывается списком писем, непрочитанные выделены (флаги берутся из IMAP);
- пагинация по тредам (25 на страницу), аватары-инициалы, sticky-шапка;
- чтение письма: `text/plain` как текст, HTML — в sandbox-iframe без скриптов и внешних картинок;
- **скачивание вложений** из письма;
- отправка письма с **вложениями** (SMTP `smtp.yandex.ru:465`, SSL), кнопка «Ответить»;
- выход из сессии.

Базы данных нет: креды и состояние живут в серверном кэше (locmem), в cookie и БД не пишутся.
Минус: перезапуск сервера = повторный вход.

## Пароль приложения

Обычный пароль Яндекс не подходит (и при включённой 2FA тоже).

1. id.yandex.ru → **Безопасность** → **Пароли приложений**;
2. создайте пароль для типа «Почта» (IMAP/SMTP);
3. включите доступ по IMAP — **только в полной (компьютерной) версии Почты**:
   в мобильном приложении и упрощённом интерфейсе этой настройки нет:
   Почта → «Все настройки» → **Почтовые программы** → включить
   «С сервера imap.yandex.ru по протоколу IMAP»;
4. используйте пароль приложения при входе в это приложение.

Если Яндекс отвечает `[AUTHENTICATIONFAILED] ... IMAP is disabled` — почти всегда
не выполнен пункт 3.

## Быстрый старт

```bash
python start.py
```

Скрипт сам поставит зависимости (если Django не установлен), поднимет сервер на
`0.0.0.0:8000` и напечатает адреса — Codespaces-ссылку и локальную.

## Запуск в Codespaces

Порт 8000 форвардится автоматически (`onAutoForward: notify`).

```bash
pip install -r requirements.txt
python manage.py migrate --run-syncdb  # не обязательно, БД не используется
python manage.py runserver 0.0.0.0:8000
```

Откройте форварднутый адрес `https://<codespace>-8000.app.github.dev`.

**Важно:** по умолчанию порт в Codespaces публичный — ссылку достаточно знать, чтобы
войти в вебморду. Поставьте видимость порта **Private** (вкладка Ports → Visibility).

## Локально

```bash
python -m venv .venv
. .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python manage.py runserver
```

## Безопасность

- `DEBUG` и `SECRET_KEY` берутся из окружения (`DJANGO_DEBUG`, `DJANGO_SECRET_KEY`);
- CSRF включён, все страницы кроме входа требуют сохранённых кредов;
- пароль приложения не логируется и хранится только в RAM;
- HTML письма отдаётся с CSP `sandbox; default-src 'none'` и в `<iframe sandbox>`.

## Ограничения v1

- нет удаления/перемещения писем, поиска и автоотправки черновиков;
- треды склеиваются по теме письма, а не по `In-Reply-To`/`References`;
- для тредов забираются последние 3000 писем папки (`THREAD_HEADER_LIMIT`);
- вложения: до 10 файлов и до 25 МБ суммарно, грузятся в память процесса;
- отправка — только plain text, без HTML-режима и подписей;
- кэш в памяти не переживает рестарт процесса.
